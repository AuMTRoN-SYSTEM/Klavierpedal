# AüMTRöN SYSTEM: Klavierpedal  

The AüMTRöN SYSTEM Klavierpedal is a dedicated, high-performance hardware expression controller that acts as a real-time analog-to-MIDI performance bridge. It is purpose-built around the Roland RPU-3 triple piano pedal, transforming its luxurious pedals and continuous analogue outputs into expressive MIDI control data with minimal latency and predictable behaviour.

The hardware is based on RP2350/Pico2w, using a 16x2 RGB LCD I2C character display, a rotating encoder (with switch), and 3 pedal inputs on 6.35mm jacks. A USB port provides the POWER/USB-MIDI function.

Klavierpedal allows the use of the RPU-3 as a standalone instrument with its own MIDI data, seperating it from your keyboard. Rather than being meant as a general-purpose controller, Klavierpedal is designed to provide a dedicated performance interface for foot-based musical expression.

Planned features include presets, calibration tools, and flexible MIDI mapping.

This repository is currently focused on architecture, documentation, and firmware development.
